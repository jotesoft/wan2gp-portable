uv 0.12.12 (Windows x64)
-------------------------
The first-run bootstrap downloads the official Astral Windows x64 archive and extracts uv.exe here.
SHA256: 3d54912924c36e862c14f427d04f2ed70a99e8001d1c30caa101f6d5711626d5

This folder is intentionally part of the portable runtime. Once populated, future installs/repairs do not need to download uv again.
